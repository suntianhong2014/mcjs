1.8.8 专属提醒（最容易踩的坑）

物品和方块用【字母名】：
1.8 起 /give 只认字母名：/give @p minecraft:diamond_sword 1
数字 ID（276）是 1.7 及以前的写法，1.8 的快照 14w03b 就删掉了
【数据值】仍然是数字，写在名字后面：/give @p minecraft:wool 1 14（红色羊毛）
没有 ^ ^ ^ 坐标：
只能用 ~ ~ ~ 相对坐标（^ 是 1.13+ 才有）
没有 @s 选择器：
@s 是 1.12 才加进去的，1.8 里用不了。
1.8 想指自己：单人游戏用 @p，多人建议直接写自己的用户名。
execute 是老语法：
/execute <目标> <x> <y> <z> <命令>，不是 1.13 的 /execute as/at/run
这三个指令 1.13 后被删了：
/testfor /testforblock /blockdata /entitydata —— 1.8 里它们是主力
声音名是老名字：
random.explode random.levelup 而不是 1.9+ 的 entity.generic.explode
颜色代码用 §：
§ 可以用 Alt+0167 输入，或直接复制：§a§b§c§d§e§f§1§2§3§4§5§6§7§8§9§0
部分药水效果 ID 不同：
24 号在 1.8 是饱和（1.9+ 改成了发光）
附魔等级可以超上限：
lvl:10 = 十级附魔（1.8 允许，只是显示没名字）

NBT 速查（1.8.8 写法）

物品附魔
/give @p minecraft:diamond_sword 1 0 {ench:[{id:16,lvl:5}]}
锋利V 钻石剑（16=锋利 见下方附魔表）
物品自定义名字（带颜色）
/give @p minecraft:diamond_sword 1 0 {display:{Name:"§b可爱剑"}}
§ 后面跟颜色代码：§b青色 §c红色 §e黄色 §6金色
物品说明文字
/give @p minecraft:diamond_sword 1 0 {display:{Lore:["§7第一行","§7第二行"]}}
Lore 是鼠标悬停显示的文字
组合：名字+附魔+不可破坏
/give @p minecraft:diamond_sword 1 0 {display:{Name:"§6逆天剑"},ench:[{id:16,lvl:10},{id:34,lvl:10}],Unbreakable:1}
最常用的「神器」写法
属性修饰（加攻击/血量）
/give @p minecraft:diamond_sword 1 0 {AttributeModifiers:[{AttributeName:"generic.attackDamage",Name:"extra",Amount:99,Operation:0,UUIDMost:1,UUIDLeast:1}]}
给武器加攻击力（Amount 是加成值）
实体：自定义名字
/summon Zombie ~ ~ ~ {CustomName:"小僵尸",CustomNameVisible:1}
CustomNameVisible:1 = 名字一直显示
实体：血量与无敌
/summon Zombie ~ ~ ~ {Health:200,Attributes:[{Name:generic.maxHealth,Base:200}]}
注意：血量上限要同时改 Attributes，否则只有 20
实体：穿装备
/summon Zombie ~ ~ ~ {Equipment:[{id:"minecraft:diamond_sword"},{id:"minecraft:leather_leggings"},{id:"minecraft:iron_leggings"},{id:"minecraft:chainmail_leggings"},{id:"minecraft:diamond_leggings"}]}
顺序：手 / 脚 / 腿 / 胸 / 头（1.8 就是这个顺序）
方块：箱子放东西
/setblock ~ ~1 ~ chest 0 replace {Items:[{id:"minecraft:diamond_sword",Count:1,Slot:0},{id:"minecraft:golden_apple",Count:5,Slot:1}]}
Slot 从 0 开始；1.8 里物品用数字 ID
方块数据：改箱子
/blockdata ~ ~1 ~ {Items:[{id:"minecraft:golden_apple",Count:64,Slot:0}]}
